## 四、已排除

1. **不是 503 重试**：四次日志里真实命中 `503 / No capacity / RESOURCE_EXHAUSTED / retrying` = **0 次**。grep 唯一捞到的 `latency_breakdown` 行是常规打点；`Terminal sandbox unavailable` 是 Windows 沙箱老告警，与模型链路无关。
2. **不是登录失效**：`token refreshed` 正常（有效期延到 03:58），全程无 `Authentication required`。
3. **不是额度/接口不可达**：`loadCodeAssist`、`fetchAvailableModels` 全部成功返回（两模型都是）。
4. **不是本机网络或 prompt 写法**：同一模板下 flash 与 hydrogen 均正常出结果。
5. **不是「0% 缓存导致冷预填充慢」**：冷预填充的前提是先发出请求；argon 连请求都没发。

## 五、仍未知

- argon 究竟卡在哪一层客户端的判定上（模型可用性判定 / 额度闸口 / 分流网关），现有 info 级日志只能定位到「请求之前」。
- 是否消耗了模型额度：没发出请求，理应未计费，但没有 usage JSON 可核，**标为未验证**。
