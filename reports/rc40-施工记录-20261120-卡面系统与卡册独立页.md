## 一、统一卡面（单一真源）

- **新增 `src/ui/card-face.js`**：导出 `renderCardFace(card)`，DOM 严格按原型 `.wc-card → .wc-face → .wc-top + .wc-art + .wc-foot`（+ 连胜/锁定角标 + 可选裂纹层）。四档气质、内描边、扫光、虹彩 conic 边全部来自 CSS 变量。
- **新增 `src/ui/card-face.css`**：由 `scripts/build.mjs` **同时前置拼进 `phone.html` 与 `wheel.html`**，两个 iframe 共用一份，杜绝双份漂移。
- **三处调用方全部换芯**：
  - 卡包：待机五卡阵 + 翻面卡（`size:'lg'`）
  - 赌场：下注槽 `.stake-card-wrap`（`sm`）+ 手牌托盘 `.bh-card`（`xs`）
  - 卡册：新独立页网格（`md`）
- 旧的 `.wish-card / .wc-mid / .wc-bot / .bh-glyph / .stake-card` 等三套样式已删，只留轻量外壳（`.wc-card{width:100%}`、拖拽壳、按钮壳）。
- 顺手清掉因此失效的 `cardCopy` 之外的无用导入与 `app.js` 的 `cardName()`。

## 二、卡面画质三档

- prefs 新键 `cardFxQuality`（`high` 流光 / `medium` 精简·默认 / `low` 极简），与 `wheelFxQuality` **完全独立**。
- 三档差异：high 常驻扫光 + 双投影 + 外发光 + 1.4px 纹样；medium 关常驻扫光（卡包翻面仍播一次）、去外发光、1.25px；low 去扫光/内描边/conic 边/阴影，背景降双色线性。
- 挂载点：`html[data-cfxq]`（小手机）与全屏轮盘同源；切档即时生效，三处同时变。

## 三、三处入口 + 双向同步

- **终端设置页**：新增「卡面画质」三选一 chips（`[data-card-fxq]`）。
- **卡册独立页**：信息栏下方同名 chips。
- **轮盘顶栏下拉**：拆成「轮盘画质 / 卡面画质」两段（`[data-fxq-opt]` ×3 + `[data-cfxq-opt]` ×3），不新增按钮。
- 数据流：轮盘 `WHEEL_PREF_SET{cardFxQuality}` → `host.js` 合并写 `api.preferences({wheelFxQuality?, cardFxQuality?})` → 快照 `view.cardFxQuality` 下发；小手机改档走 `api.preferences` + `theme()`，`receive()` 的 signature 已把两个画质键纳入。
- **顺带修掉 4N 指出的同步 BUG**：轮盘原来读 `data.fxQuality`（顶层），而宿主把它放在 `view.fxQuality` 里 → 画质改成永远不生效；现在 `WHEEL_INIT/OPEN` 与 `WHEEL_STATE_SYNC` 都按 `data.view?.fxQuality / cardFxQuality` 覆盖。

## 四、卡册独立成页

- `open-binder` 不再 `bagTab='cards'; bagModal()`，改走 `screens.binder()`：标题「星愿卡册」、图鉴进度、✦积分/🃏藏卡汇总、卡面画质条、四档筛选（带计数）、网格、空态。
- 背包弹窗的 cards 分页**保留**作过渡（内部已换新卡面），顶部加「前往星愿卡册 ›」跳转；17 条零 API 用例不受影响。
- 叠卡兼容点：每张卡容器带 `data-rarity / data-card-code / data-pool-tier`，后续按 `(rarity, cardCode)` 聚合即可，不用重构骨架。

## 五、星愿卡包

- **点击爆彩修好了**：根因是 `.wf-board.is-pack .wf-fx{display:none}` 把粒子画布藏了；现在 pack 模式 `.wf-fx` 显示（z-index 12），`.wf-svg` 仍隐藏。
- 粒子改成**池化**：`fxParticles` + 单一 rAF 循环，支持「单卡位置爆彩」（按卡槽包围盒换算 canvas 坐标）和连点叠加；1.15s 无活跃粒子自动停帧。
- 三档粒子：high 灰14/红22/金32/虹42、向心 34；medium 约 55%；low 0（不启 rAF）。
- 「全部翻开」改为逐张延时触发（180ms），一键全翻也有依次爆彩。
- **「跳过动画」按钮恢复**：`closest()` 选择器漏了 `[data-skipspin]`，现已补上。
