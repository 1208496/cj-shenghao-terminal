## 二、rc.28.1 长标签压字修复（交接文档标注「下次要实测确认」项）

### 测量方法
DOM 探针逐行读 `.kv-k` 的 `getBoundingClientRect().right` 与 `.kv-v` 的 `.left`，差值即重叠像素；同时比较 `scrollWidth` 与 `clientWidth` 判断是否被省略号截断。

### 结果（悬浮态，面板 299px）

`grid-template-columns: 103.73px 181.67px` —— **8.2em 已生效**（基准 ≈12.65px × 8.2 ≈ 103.7px）

| 标签 | 标签宽 | 文字宽 | 截断 | 重叠 |
|---|---|---|---|---|
| 生理周期： | 104px | 104px | 否 | 0 |
| 孕期： | 104px | 104px | 否 | 0 |
| 处子状态： | 104px | 104px | 否 | 0 |
| 胸部详情： | 104px | 104px | 否 | 0 |
| **阴部户型与色泽：** | 104px | 104px | 否 | **0** |

| 阴毛类型： | 104px | 104px | 否 | 0 |

**10 行全部重叠 0、零截断。** 交接文档里点名的四个 7 字标签（阴部户型与色泽 / 阴部紧致与状态 / 后庭外观与状态 / 体香与特征）全部不再压到数值列，也没有被省略号吃掉。

## 六、发现的问题

### 1. 运行时资产面板只读，无编辑入口（**需确认是否为设计意图**）

- 「我的 → 持有资产」展开后：资产条目正确显示（办公笔记本电脑 / 其他·本人住所 / ¥6,000 / 描述），8 个分类筛选 tab（全部/房产/座驾/产业/游艇专机/奢品/藏品/其他）都在
- 但**资产区内没有任何编辑/新增按钮**，可点元素只有那 8 个筛选 tab
- 对照：开局向导第 2 步的资产卡确实有「编辑 + 移除」双按钮（rc.28 新功能，文档已验证）
- **推测**：运行时只读是设计意图（只能靠 AI 结算修改资产），向导里才允许手改。如果预期运行时也能编辑，这就是缺口。

### 2. `.limit-grid` 在详情页未检出

详情页 `dossier-grid` 检出为 4 列，但 `limit-grid` 查询返回 `null`。可能位于「🔥 经历·尺度」折叠块内（该块本次未展开测量）。不排除选择器时机问题，**记录为未确认**，不是已证实的 bug。

### 3. 测试工具盲区（非卡的问题）

悬浮态下 `page.screenshot()` 的可见区与 `window.innerWidth` 不一致（截图 1303 宽 vs 视口 1629 宽），导致 `position:fixed` 的悬浮面板（x=1326）拍不进截图。本次通过**临时改写 `style.left/top` 把面板移入截图区、拍完还原**绕过。建议后续在 `ego-st-lib` 的 `shot()` 里加一个 `clipTo(selector)` 变体。
