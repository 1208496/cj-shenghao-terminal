# 零 API 角色卡测试记录（神豪终端 · 从 rc.36 起通用）

> 目的：把「不花一分模型 API 也能把角色卡 UI / 经济 / 导航测到底」的方法固化下来，新对话直接照做。
> 方案来源：`AGY_PLAN_TEST_NOAPI.md`（4Neon，`925f7d25`，360 s）；落地脚本：`scripts/test-noapi-seed.mjs`、`scripts/test-noapi-run.mjs`。
> 首次全矩阵实跑：2026-11-20 01:34–02:00（8001，ego 运行时）。

## 一、为什么能做到零 API

1. **界面只认状态，不认生成**：`host.js` 只要从末楼倒序读到能过 Zod 的 `stat_data.shenghao`，就把 `#cj-shenghao-phone-frame` 设为 `display:block`；`app.js` 看到 `view.state` 就跳过 `#wizard` 开局表单。整个过程与模型无关。
2. **轮盘/赌场/商城全是本地引擎**：`PLAYER_WHEEL_SPIN`、`PLAYER_CARD_DRAW`、`PLAYER_CASINO_BET`、`PLAYER_CARD_REDEEM`、`PLAYER_SHOP_BUY` 都是确定性哈希 + 纯状态运算，一次网络请求都不发。
3. 所以：**只有「模型会不会照抄字段、变量会不会正确落盘」这一类才必须真生成**；其余全部可零成本验。

## 四、必须记住的三条硬规则（违反会得到假结论）

1. **状态写在末楼**（我们写 1 楼、`is_user:true`）的 `variables[0].stat_data.shenghao`，并带 `initialized_lorebooks: {"<当前世界书名>": []}`；否则 `[InitVar]` 会把状态重置成 `null`。
2. **每轮换 `meta.initKey`**：同 key 会让 `host.js` 把 `localStorage['cj-shenghao:ops:v1:<branch>']` 的旧操作日志重放进新状态，测出幽灵数据。
3. **刷新后先重新选卡进聊天再断言**：8001 的 `auto_load_chat=false`，刷新必然回欢迎页；直接断言 `revision` 永远为 0。

## 五、落地时踩过的坑

1. **ego 运行时里 `process.execPath` 是 `ego.exe`**：`execFileSync(process.execPath, [...seed])` 会把脚本当应用参数、静默不执行，导致「用了上一轮预置仍然 PASS」的假绿。现在只有 execPath 真的以 `node(.exe)` 结尾才用它，否则用 PATH 里的 `node`，并加了 `SEED_NOT_WRITTEN` 新鲜度守卫（预置文件早于本次启动即报错）。
2. **Windows 中文 stdout 编码**：子进程 JSON 走 stdout 会乱码，seed 增加 `--out <file>`，runner 读文件而不是解析 stdout。
3. **轮盘卡死的真因不是性能**：子页原本用 `event.source !== window.parent` 校验父端消息，但真酒馆里本体跑在 TavernHelper 的 iframe 里，`event.source` 是其宿主 iframe 而非顶层窗口 → `INIT` 全被丢弃、盘面建不出来、只剩锁滚动的暗罩。现在只认 `channel + nonce`，并加 READY 重发与 `WHEEL_BUILT` 回执。
4. **ego 没有 `frameLocator`/`route`**：所有 iframe 操作走 `contentDocument` + `page.evaluate`；网络层没有 `route.abort`，改用 `fetch`/`XHR` 审计哨兵 + 全程不触发生成。

## 六、覆盖边界（写清楚，免得上错船）

| 能零 API 验 | 必须花一次真实生成 |
|---|---|
| 小手机出现、五页导航、财富页/轮盘页结构、背包与商城外观、三盘入口卡数据 | 协议/世界书/正则改动后，模型是否照字段写、`<UpdateVariable>` 是否被正确吞掉 |
| 轮盘全屏、握手、落点高亮、结果卡、保底推进 | 一轮正文生成后，`stat_data.shenghao` 是否被 MVU 正确写回、`revision` 是否前进 |
| 赌场押注/兑换、商城扣分、星愿圣盘解锁/限次/报价（引擎侧） | 模型侧数值是否越权、字段是否漏写（`pendingBasicProfiles` 等） |
| 刷新回读、切聊天/删楼/切 swipe 回归 | 生成过程中的并发锁（`GENERATION_BUSY`）只在真实生成里出现 |

## 七、后续怎么扩展
