# rc.39 追加记录 · 第三轮（2026-11-20 22:45–23:00）：星愿卡包五阶段演出

依据方案 §三（对标 `reports/rc39-proto-pack.html`）。目标是让开卡从"点一下翻一张"变成五段有节奏的仪式。

## 五个阶段现在各做什么

| 阶段 | 实现 | 三档画质差异 |
|---|---|---|
| **① 待机阵 IDLE** | 五张代表卡弧形悬浮（灰/红/星愿秘印/金/虹），圣典未解锁时灰阶压暗（rc.38 已有） | 极速档关呼吸动画 |
| **② 环绕洗牌 ORBIT** | 点确认后五卡向圆心收拢回旋（`pkOrbitSpin`）+ **Canvas 金色向心粒子**（新增 `convergeParticles()`），可点「跳过动画」 | 璀璨 1350ms/34 粒 · 均衡 950ms/16 粒 · 极速 0ms 直接进撕封 |
| **③ 撕封启包 SEALED→BURST** | 右滑撕开或「一键撕开」；破封按本包最高稀有度爆对应色粒子（rc.38 已有） | 极速档 0 粒子 |
| **④ 翻面揭晓 + 扇形收束 FAN→SETTLED** | **新增**：三张哥特卡背错峰落台（`pkDeal` 90ms 递延）→ 点一张 **3D `rotateY(180deg)`** 翻面 → 四档揭晓光效（灰银雾 / 红绯脉 / 金熔光+轻震 / 虹棱镜+强震）→ 三张全翻后 `.is-settled` 收束成扇形并亮出提示 | 均衡关震动、光晕降到 0.62 · 极速关光效与翻面动画 |
| **⑤ 收藏入册 COLLECT** | **新增**：点「全部收入卡册」，三张卡各自按自己的位置飞向右上角（卡册所在方向）`translate + scale(.16)`，纯 transform、不重排 | 璀璨 380ms · 均衡 260ms · 极速瞬切 |
