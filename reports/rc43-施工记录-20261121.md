## 六-补 · 「正文获得资产，资产会不会出现」追查结论（2026-11-21 19:2x）

**答案：修好之后会。**

**根因（不是模型不报，是它用错了事件类型）**：抓完整 `<UpdateVariable>` 块后看到，模型把「林总无偿过户 SF90」写成
`{"type":"CASH_TRANSACTION","direction":"IN","amountYuan":"0",...,"asset":{"assetId":"asset_ferrari_sf90","kind":"CAR",...}}`
—— 事件类型是现金流，金额 0，资产对象内嵌在里面。引擎只按现金流处理（0 元、无流水），**资产对象被丢掉**，所以财富页永远是空的。

**修法（脚本兜底，不依赖模型）**：`engine.js` 的 `normalizeEvent` 增加改判 —— `CASH_TRANSACTION` 带 `asset` 且金额为 0 或缺失时，一律改判成 `ASSET_GRANT`。

**实测（Live-3，干净环境）**

| 项 | 结果 |
|---|---|
| 模型原样输出 | 仍是 `CASH_TRANSACTION`（`blockHasGrant: false`） |
| 改判后 | `assetsBefore 1 → assetsAfter 2`，新增 `法拉利 SF90 / CAR / ¥498 万 / acquisitionIsInitial: true`，账本 +1 条 `ASSET_GRANT` |
| 财富页 UI | **持有资产 2 项**：湾流 G700（¥1,000 万）、法拉利 SF90（¥498 万）；总资产估值 ¥1,648 万（截图 `reports/rc43-shots/wealth-with-sf90.png`） |
| 现金 | 无变化（不凭空加钱） |

顺手修掉一个 UI 矛盾：补录资产的 `ownershipNote` 写着「玩家补录 · 待估值」，估值落定后仍显示"待估值"，现在随估值一起改成"已估值"。

单测补 1 条（模型那条原样事件喂进 `settleEvents`，断言资产入账、现金不变），总数 **435 / 435**。
