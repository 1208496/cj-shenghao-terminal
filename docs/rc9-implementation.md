## 有效决定

- 项目 AGENTS.md 优先于计划中的旧档迁移建议：尚未向玩家发行，使用 schemaVersion=3 新聊天，不建立旧档迁移层，不覆盖已有聊天。版本 rc.9，cardContractRevision=5。
- 奖励初始为零；消费与暴击仅原额入池；提现锁定提现前现金对应的五档倍率。领取绑定奖励事件与原额，历史批次不可变。
- 已提现消费退款按原提现倍率生成该人物专属追回记录。只抵扣她后续提现的理论到账，不立即扣现金、不跨人物抵扣；不足额继续保留。抵扣可使本笔实际到账为零，仍是有效清算。隐藏期间退款同样履行真实退款及对应权益冲正。
- 一般消费部分退款默认按原分摊累计比例冲减；提供 refundAllocations 时按可核验明确受益份额冲减。资产部分退价保留产权；全额退货须明确 returnedAsset=true，已赠出资产须 receivedBack=true 才退回外部，禁止产权凭空跳转。
- 金额以安全整数分保存，字符串元最多两位小数，可带 ¥/￥、元、万、亿；换算与乘法用 BigInt 校验，超过 JS 安全整数时整笔拒绝。
- 默认玩家颜值60，可在确认开局前自由选择1–100；女性正式建档须提供分数，九类补全不得改变。
- 好感只经事实事件结算：正向须 meaningfulInteraction=true 及正文证据；模型报基础变化。<70时按玩家颜值修正。普通同轮累计绝对变化最多12，明确 majorTurningPoint=true 且有至少12字逐字转折证据时最多30；负向不加颜值修正。直接字段候选需相同证据并转换至同一事件入口。
- 消费记录只从统一账本、分摊、退款和奖励领取投影，分页20条；转赠是零现金产权记录。等级与未领池不重复持久化。
- UI延续现有三页、三主题及字号/缩放。新字段由原开局表单和人物详情承载。世界书不包含女性名单；玩家选择的开局熟人属于用户设定。
