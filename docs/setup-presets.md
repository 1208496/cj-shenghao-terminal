# 开局预设与熟人编辑

2026-11-16，rc.7本地验收卡，cardContractRevision=3。

## 行为

- “此刻”玩家姓名旁移除User标签，内部USER身份标识不变。
- 开局全部可编辑填写框提供至少3个预设，包含文本、多行描述、数字、日期、时间、资产和熟人资料。居住方式与资产类别继续沿用原生下拉。允许不选择预设、自由输入或选择后再修改。
- 填写框获得焦点时打开预设，点击或方向键+Enter选择；Escape只收起预设，下一次Escape才关闭所在弹窗。选项挂载在当前文档顶层，避免被滚动弹窗裁切；支持上下自动放置和长文本换行。
- 初始熟人提供6位成年女性候选，选择只填入待编辑表单，确认添加后才加入开局草稿，不自动到场、不生成九大档案。
- 熟人列表所有人物都有“编辑”和“移除”，包括手动添加和预设添加者。编辑读取现有值，保存替换原记录并保留ID，取消不写草稿；可编辑姓名、年龄、关系、好感、职业、性格、外貌、身材、身体数据、备注与是否同场。
- 预设仅为开局创作素材，不调用4A处理玩家运行数据。现有正式初始化、简易生成和奖池规则继续沿用。

## 4A来源与人工审核

通过 `gemini-card-authoring` 的本地客户端调用主模型 `pg-gemini-4-argon`，单次custom任务；返回模型同名，fallbackUsed=false。凭证由技能读取，没有进入项目、输入或回执。原始提案回执：`evidence/gemini-setup-presets.json`，仍标记proposed-only。

人工审核后维护源为 `src/ui/setup-presets.json`：将3个男性候选改为符合本项目收录机制的成年女性，调整名字、代词与身体数据；去掉天气中的固定时段；将只含房屋使用权的资产选项改为住房产权；以江城区对齐默认城市；去掉预设对玩家大学经历和年龄的强制假设。没有把候选全文直接当作定稿。
